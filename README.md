# 云序科技 · 企业数字服务商城

基于 **React + Vite + Tailwind CSS v4** 的企业软件服务商城前端项目。适用于计算机软件开发、系统集成、数据处理、技术咨询等服务类产品，不按实物电商的库存、物流模型设计。

## 环境要求

- Node.js 20.19+（建议使用当前 LTS）
- npm 10+

## 本地运行

```bash
npm install
npm run dev
```

按终端提示打开本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 已实现页面与交互

- 首页：品牌介绍、服务分类、精选服务、采购流程。
- 服务商城：分类筛选、关键词搜索、价格排序。
- 服务详情：服务范围、交付内容、周期、保障说明、数量选择。
- 采购清单：增减数量、删除项目、自动汇总金额。
- 确认订单：企业名称、联系人、手机号、邮箱、纳税人识别号、项目备注、支付方式。
- 支付确认：演示支付确认，订单状态更新为“已支付”。
- 我的订单：订单列表、支付状态筛选、待支付订单入口。
- localStorage：购物车和订单在当前浏览器持久化。

## 重要：支付安全边界

当前项目是**可交互的前端演示**。支付按钮只会修改浏览器本地订单状态，不会发起真实扣款；企业银行转账也没有展示真实账户信息。

上线真实支付前，必须补充后端服务，例如：

1. 用户身份认证、企业/联系人资料管理。
2. 服务商品、报价、订单、合同、发票等数据库模型。
3. 服务端重新计算订单金额，不能信任浏览器提交的价格。
4. 接入合规支付机构的服务端下单、签名校验、异步支付通知与退款流程。
5. 订单状态仅由服务端在验证支付回调后更新，防止前端伪造“支付成功”。
6. 服务交付流程、验收记录、售后工单、权限审计和隐私政策。

## 定制说明

- 服务产品数据集中在 `src/data.js`。
- Tailwind CSS v4 通过 `@tailwindcss/vite` 插件集成，CSS 入口使用 `@import "tailwindcss";`。
- 当前使用 React Router v7 的 `react-router` 包。
- 当前未接入真实 API，所有订单均为浏览器本地演示数据。
